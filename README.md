# Single-Page HTML CV

Este es un proyecto basado en los retos de [roadmap.sh](https://roadmap.sh/projects/single-page-cv). El objetivo principal es construir la estructura de un Curriculum Vitae (CV) de una sola página utilizando únicamente HTML semántico, estableciendo una base limpia y accesible antes de aplicar estilos.

## Objetivos del Proyecto

- **HTML Semántico:** Utilizar las etiquetas adecuadas (`<header>`, `<section>`, `<article>`, `<footer>`, etc.) para estructurar el CV de forma correcta.
- **Estructura Clara:** Crear secciones bien definidas para educación, habilidades e historial laboral.
- **SEO Básico:** Incluir etiquetas meta esenciales en la sección `<head>` para la optimización en motores de búsqueda.
- **Open Graph (OG):** Añadir etiquetas OG para mejorar la previsualización al compartir la página en redes sociales.
- **Favicon:** Configurar un ícono para la pestaña del navegador.

## 🛠️ Tecnologías Utilizadas

- **HTML5**
